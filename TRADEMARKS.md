# Trademark policy

The code of Graphersal is licensed under Apache-2.0. The licence covers the code, not the project's name and logo
(Apache-2.0, section 6). This page says how the name "Graphersal" may be used.

You may, without asking:
- refer to Graphersal by name to describe that your software uses, supports or is compatible with it
  ("built with Graphersal", "a Graphersal storage backend");
- use the name in articles, talks, tutorials and comparisons;
- distribute unmodified official releases under the name.

Please ask first before:
- naming a fork, a modified build, a product, a hosted service or a company "Graphersal" or something confusingly
  similar;
- using the name or logo in a way that suggests your product is official, endorsed by or affiliated with the
  project.

A fork is welcome under its own name; its documentation may say that it is based on Graphersal.
