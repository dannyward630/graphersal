# Graph file formats (feature `io`)

Agent guidance. Not packaged. Neither format carries the schema.

- **GraphSON 3.0** (`io/graphson.rs`, the primary exchange format for Gremlin users; dependency-free on `physical::read_json`; docs `book/src/users_guide/graphson.md`; type table in the module doc). Import reads the line form (one vertex per line) and the wrapped form `{"vertices": [...]}`, 3.0/2.0 typed and untyped 1.0, leniently: `g:Int32` -> `int64`, `g:UUID` -> `uuid`, `g:List`/`g:Set` -> `array`, `g:Map` -> `object`; `g:Date`/`g:Timestamp`/`gx:Instant`/`gx:OffsetDateTime`/`gx:ZonedDateTime` (zone id dropped, reported) -> `datetime`, `gx:LocalDate`/`gx:LocalDateTime`/`gx:LocalTime` -> `date`/`localdatetime`/`time`, `gx:Duration`/`gx:Period` -> `duration`. Every type we cannot hold (`gx:Year`, `gx:MonthDay`, `gx:OffsetTime`, ...) is SKIPPED and listed in the `ImportReport`, never converted. Ids become strings, `"A::B"` labels split, multi-valued properties one array, meta-properties the reserved `_meta` object. Bounded by `GraphSONImport::max_text_bytes` per line/document and the value depth. Export writes the line form with typed values (TinkerGraph loads it), `_meta` back as meta-properties when it has the import shape. API `GraphSource::from_graphson(_reader)`, `GraphSONImport::load(_file)`, `GraphImport::import_graphson(_reader)` (one unit), `GraphExport::export_graphson(_writer)`, Rhai `import_graphson`/`importGraphson`, `export_graphson`/`exportGraphson`; `from_file` picks GraphSON for `.json`/`.jsonl`/`.graphson`.
- **GraphML** (`quick-xml`): values through the physical codec; logical types restored on import only from the TARGET graph's stored schema (set the schema first, then import): declared `uuid`/temporal from canonical text, `array`/`object` from JSON text (`physical::read_json`); undeclared text stays a string (root rule 7). Graph-level `<data>` is ignored; the schema travels as its own JSON (the playground saves both files and its "Load from file" sets an optional schema file on the new empty graph before the import: a loaded file never keeps the previous graph's schema).
- `std::fs` is allowed inside `io` only (on wasm32 it errors, it must never panic).
