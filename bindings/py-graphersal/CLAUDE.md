# py-graphersal (Python package `graphersal`)

Agent guidance for the PyO3/maturin binding (`abi3-py310`, `publish = false`). Build/test commands are in the root `CLAUDE.md` and `README.md` here.

- `Graph.from_graphml`/`from_graphson` take `schema=`/`mode=` (set on the empty graph first, then the file imported as one unit); `graph.import_graphml`/`import_graphson` import into a live graph as one unit (no `policy=`: they wrap `GraphImport`, not the script entry). Scripts allow everything; `policy=AccessPolicy..` per call.
- Scripts evaluate on a 64 MiB stack thread (`script_thread.rs`). The extension installs the `alloc-tracking` allocator in `lib.rs`; as a `cdylib` it counts only its Rust heap, never Python objects, so with `memory_limit="auto"` the headroom must cover the Python side.
- Embedders (`src/embedder.rs`, feature `model2vec` on): `graphersal.Embedder(name, fn, *, dimension, ..., model=None)` wraps a Python callable (rows as lists/1-D buffers/`Vector`s or ONE 2-D float32/float64 buffer read through `memoryview`, no numpy dependency; wrong N/D -> `BadOutput`, an exception (also `KeyboardInterrupt`) -> `Failed` with type + message; attaches with `Python::try_attach`). `graphersal.Model2Vec(name, path, *, model=..)` is a subclass (local directory only, never downloads; `model` -> `Model2VecOptions::with_repo`, identity = the CLI download's). Every Graph constructor/loader and Store opener takes `embedders=`/`default_embedder=`; the registry is a `RegistryCell` (copy-on-write `Arc<Embedders>`, shared by every `store.graph`); scripts get it through `Embedders::scope` around `eval_value_*`. `graph.embed_property` runs on a thread while the caller polls `check_signals` (Ctrl+C cancels); failure `EmbedPropertyError.report`.
- **GIL rule:** no binding path waits for a graph lock while holding the GIL (every lock inside `py.detach`), because a Python embedder runs under the graph's lock and needs the GIL. `tests/test_embedders.py` guards it in a child process.
- Store: `graphersal.Store` (`create_file/open_file/convert/upgrade`, `prune/compact/compaction_advice`; `err.cause` = `StoreFailure::name()`).
